# 💸 Expense Tracker

A modern, responsive personal finance visualizer built with **Next.js**, **React**, **shadcn/ui**, **Recharts**, and **MongoDB**. This app helps you track expenses, categorize transactions, set monthly budgets, and gain insights into your spending habits.

---

## 🚀 Features

- Add, edit, and delete transactions
- Categorize expenses and view them in pie charts
- Monthly expenses bar chart
- Set and compare monthly category budgets
- Dashboard with total spending and insights

---

## 🛠️ Tech Stack

- **Next.js** (App Router)
- **React**
- **TailwindCSS + shadcn/ui**
- **Recharts** for data visualization
- **MongoDB** (Mongoose for schema)
